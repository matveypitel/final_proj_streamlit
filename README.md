# Помощник поддержки учебного сервиса

Веб-чат для учащихся онлайн-школы «КодКласс». Отвечает на вопросы по правилам школы
с источниками (документ и страница), показывает статус своих заявок и готовит новую заявку,
которую пользователь создаёт кнопкой.

## Как запустить

Все команды — из папки `ai-course`.

1. Создайте и активируйте окружение:
   - Windows: `python -m venv .venv`, затем `.venv\Scripts\activate`
   - macOS: `python3 -m venv .venv`, затем `source .venv/bin/activate`
2. Установите библиотеки: `pip install -r requirements.txt`
3. Скопируйте `.streamlit/secrets.toml.example` в `.streamlit/secrets.toml` и заполните.
4. Положите документы в `final_project_solution/docs` (по умолчанию — четыре файла из `module3/docs`)
   и соберите базу знаний: `python final_project_solution/build_index.py`
5. Запустите: `streamlit run final_project_solution/app.py`
6. Войдите как Анна или Борис с паролем из `APP_PASSWORD`.

Чтобы начать с чистого листа, скопируйте `data/tickets_start.json` в `data/tickets.json`.

## Настройки

Секреты — в `.streamlit/secrets.toml` (локально) или в поле Secrets на хостинге:

| Секрет | Зачем |
| --- | --- |
| APP_PASSWORD | Пароль входа в приложение |
| ANTHROPIC_API_KEY | Ответы модели (или OPENAI_API_KEY и AGENT_MODEL = "openai:<модель>") |
| OPENAI_API_KEY | Эмбеддинги для поиска по базе знаний — нужен всегда |

В `config.py`: модель (`AGENT_MODEL`), лимит шагов агента, лимит сообщений за диалог,
длина текста заявки, порог поиска `MAX_DISTANCE`, пути к данным.

## Как проверить

```
python final_project_solution/run_checks.py
```

Восемь сценариев: документы, вопрос вне базы, свой и чужой статус, черновик без записи,
сбой хранилища, возврат денег и смешанный вопрос. Ожидается «Пройдено: 8 из 8».
Сценарии приёмки в браузере — в уроке 36; сбой хранилища включается переменной `TOOLS_DOWN=1`.

## Ограничения

- Учебный прототип для демонстрации, а не промышленный сервис.
- На бесплатном хостинге файловая система временная: заявки и журнал пропадают при перезапуске,
  сне или новой публикации. Локально данные сохраняются.
- Учебный вход: два пользователя и общий пароль.
- Не больше 20 сообщений в одном диалоге; кнопка «Новый диалог» начинает новый.
- Ответы модели могут ошибаться — проверяйте источники.
